<details>
<summary>Where to Start: A Suggested Learning Order</summary>

With ten platforms available, the hardest part is knowing where to begin. Here is a practical order based on background:

**If you have no ML background:**
Start with Google's "Fundamentals of AI" on grow.google. It covers concepts without requiring maths or coding. Follow it with IBM SkillsBuild's "AI Foundations" — structured, free, and self-paced.

**If you can code but haven't touched AI:**
Start with DeepLearning.AI's short courses (most are 1-4 hours). Andrew Ng's teaching style is exceptionally clear. Then move to Hugging Face's NLP course to work with real models.

**If you're a developer who wants to build with LLMs:**
Start with Anthropic's course at anthropic.skilljar.com — it is focused specifically on building with Claude. Then OpenAI Academy for GPT and function calling. Then AWS Skill Builder for deploying models at scale.

**If you want low-level understanding:**
NVIDIA's CUDA documentation and developer resources are the most technically rigorous option on the list. Hard, but nothing else teaches you what's actually happening on the hardware.

The mistake most people make: trying all ten at once. Pick one, finish it, build something, then pick another.
</details>

<details>
<summary>What Makes Each Platform Unique</summary>

Each platform has a distinct angle. Knowing the difference saves time:

**Anthropic (anthropic.skilljar.com)** — Focused on responsible AI use and building with Claude. Best for: developers building production AI applications who care about safety and reliability.

**Google (grow.google/ai)** — Broad, beginner-friendly, covers AI in business as much as technical implementation. Best for: non-technical learners and those working with Google Cloud.

**Meta (ai.meta.com/resources)** — Heavy focus on open-source models (Llama). Best for: developers who want to self-host models and avoid vendor lock-in.

**NVIDIA (developer.nvidia.com)** — GPU programming, CUDA, and deep learning hardware. Best for: engineers who need to understand training infrastructure.

**Microsoft (learn.microsoft.com)** — Azure AI services, Copilot integration, enterprise deployment. Best for: developers in Microsoft/Azure environments.

**OpenAI (academy.openai.com)** — GPT models, function calling, Assistants API. Best for: developers building on the OpenAI platform.

**IBM (skillsbuild.org)** — Enterprise AI, Watson, AI ethics. Best for: enterprise teams and those interested in AI governance.

**AWS (skillbuilder.aws)** — SageMaker, Bedrock, and AWS AI services. Best for: teams deploying on AWS infrastructure.

**DeepLearning.AI** — Core ML theory, practical deep learning, LLM fundamentals. Best for: anyone who wants genuine understanding, not just tool usage.

**Hugging Face** — Open-source models, transformers, datasets, spaces. Best for: practitioners who want hands-on model work without writing training code from scratch.
</details>

<details>
<summary>Building a 90-Day Learning Path</summary>

A realistic structure for going from zero to building AI applications in 90 days:

**Days 1-30: Foundations**
- Week 1-2: Google Fundamentals of AI (grow.google)
- Week 3-4: DeepLearning.AI "AI for Everyone" + one short course on prompting

**Days 31-60: Hands-On**
- Week 5-6: Hugging Face NLP course (work through code examples)
- Week 7-8: OpenAI Academy — build a simple chatbot and a RAG application

**Days 61-90: Build and Deploy**
- Week 9-10: Anthropic course — focus on production patterns and safety
- Week 11-12: AWS or Azure deployment — get something live

At each stage, build something. The learning compounds dramatically when theory becomes code. A simple project (summariser, classifier, chatbot) is worth more than two more courses.

What to skip if time is short: NVIDIA and IBM are valuable but specialised. Come back to them once you have a working application and specific hardware or enterprise questions.
</details>

<details>
<summary>What to Build After Each Resource</summary>

The best way to validate what you learned is to build a small project immediately after each course:

**After Google Fundamentals** — Write a one-page document explaining how a neural network works in plain English. If you can explain it, you understood it.

**After DeepLearning.AI short courses** — Build a basic prompt pipeline: take a document, summarise it, extract key points, generate follow-up questions. Chain three LLM calls together.

**After Hugging Face NLP course** — Fine-tune a small sentiment classifier on a dataset you care about. Deploy it to a Hugging Face Space.

**After OpenAI Academy** — Build a simple RAG system: embed documents, store in a vector database, retrieve relevant chunks, answer questions. This pattern underlies most production AI applications.

**After Anthropic course** — Add safety guardrails and structured output to your RAG system. Ship it as a simple web tool.

**After AWS/Azure** — Deploy your tool with authentication, rate limiting, and monitoring. Now you have a real project to put on a portfolio.

The resources are free. The time is the investment. Protect it by building something concrete after each one.
</details>
